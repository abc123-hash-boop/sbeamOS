# SbeamOS Live ISO boot contract

The ISO image is expected to use the following layout:

```text
SbeamOS.iso
├── boot/
│   ├── grub/
│   │   └── grub.cfg
│   ├── vmlinuz
│   └── sbeamos-live-initrd.img
└── LiveOS/
    └── rootfs.squashfs
```

`vmlinuz` is a version-independent copy or symlink to the kernel selected for
this image. `sbeamos-live-initrd.img` is the dedicated non-host-only Dracut
initramfs generated by `scripts/chroot/14-live-initrd.sh`.

The GRUB entries boot the SquashFS root using Dracut's `dmsquash-live` support:

- `root=live:CDLABEL=SBEAMOS` locates the ISO/live medium by its volume label.
- `rd.live.dir=LiveOS` selects the directory containing the root image.
- `rd.live.squashimg=rootfs.squashfs` selects the SquashFS filename.
- `rd.sbeamos.live=1` enables the SbeamOS-specific pre-pivot media handoff.

The SbeamOS pre-pivot hook exposes the mounted medium at `/cdrom` and the root
image at `/run/sbeamos-live/rootfs.squashfs` for future installer integration.

The ISO builder must keep the ISO volume label exactly `SBEAMOS` and copy this
configuration to `/boot/grub/grub.cfg`. UEFI/BIOS bootloader installation and
actual boot validation are not implemented by this configuration file alone.
